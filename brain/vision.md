# Visión
ERP de inventarios open source para pymes (Windows y Linux), con paridad funcional progresiva respecto a ERPs comerciales colombianos (p. ej. Siesa).

- **Alcance v1:** catálogo, bodegas, kardex, costeo PEPS/promedio, compras, ventas, cartera.
- **Después:** facturación electrónica DIAN, contabilidad (PUC), POS offline, manufactura, nómina electrónica.
- **No-objetivos:** copiar código, UI o marca de terceros; certificarse como proveedor tecnológico en v1 (se integra uno autorizado).
- **Licencia propuesta:** AGPLv3 (pendiente de confirmar → ADR 0002).
