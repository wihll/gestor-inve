# Roadmap
1. **Fase 1 (3-4 m)** Inventarios MVP: seguridad, catálogo, bodegas, movimientos, kardex PEPS/promedio, reportes, instaladores.
2. **Fase 2 (3 m)** Compras, ventas, terceros, cartera, impuestos (IVA, ReteFuente, ReteICA, ReteIVA).
3. **Fase 3 (4 m)** Facturación electrónica DIAN (UBL 2.1) vía proveedor tecnológico; contabilidad y PUC.
4. **Fase 4** POS offline, manufactura, nómina electrónica, CRM, BI, plugins, localización multi-país.
Criterio de salida por fase: tests de dominio verdes, instalador en Windows y Linux, docs actualizadas.
